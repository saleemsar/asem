# Desktop computer papercraft

* `pdf_large/` – **large model on a 50 × 50 cm base**. Every part is a fully closed box, split into pieces that each fit on one A4 page. Start with `ALL_PARTS_LARGE.pdf` (22 pages) or the individual files.
* `pdf/` – the first, small version (38 × 27 cm base).

Print at 100 % ("Actual size"). Regenerate with `python3 make_papercraft_large.py`.
