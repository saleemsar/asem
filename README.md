# OS Concepts – Chapter 1, animated

`ch1-animated.html` is an interactive, step-by-step animated walkthrough of the Chapter 1 ("Introduction") slides from *Operating System Concepts*, 9th ed. (Silberschatz, Galvin and Gagne).

- 52 animated scenes covering all 58 slides (closely related slides are combined).
- Each scene builds up one component at a time, with a written explanation of every component.
- Controls: Next/Back (← →), previous/next scene (Shift + ← →), Play/Pause (Space).

The file is a page fragment published as a claude.ai Artifact; to open it locally, wrap it in a basic `<!doctype html><html><body>…</body></html>` or open it in any modern browser directly.
